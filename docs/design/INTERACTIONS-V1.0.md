# P0 页面与交互契约（M0-05）

开发稿：2026-09-07。正式 PO/TL 审核待统一进行。低保真页面见 m0-05-prototype.html；原型不是产品实现，不连接真实凭证或上游。

## 导航和主流程

匿名：初始化状态 → 初始化（仅一次）/登录。登录后：组织选择 → 总览 → 供应商/模型 → 目标 → 预检 → 配置/估算 → 运行 → 结果 → 探针/样本 → 复核/导出。辅助导航为基线、规则、审计、系统。历史比较由结果页进入。

## 首次初始化（setup）

- 路径/流程：未初始化 → 建立首个组织与管理员 → 登录。
- 信息/操作：组织名称、管理员用户名、管理员密码、密码确认。
- 异常：保存成功仅跳转登录；并发初始化冲突重新读取状态，绝不覆盖账号。
- 权限与安全：匿名仅可访问初始化状态和健康；初始化完成后写入口关闭。

## 登录与会话（login）

- 路径/流程：登录 → 选择组织 → 检测总览。
- 信息/操作：用户名、密码；改密入口；退出所有会话。
- 异常：失败显示统一文案；429 展示等待时间；会话过期返回登录并保留非敏感导航地址。
- 权限与安全：Cookie 会话，不在 URL/localStorage 保存凭证；写请求携带 CSRF。

## 检测总览（overview）

- 路径/流程：组织范围 → 7/30 天 → 目标或历史任务。
- 信息/操作：目标数、任务数、风险文字分布、异常趋势、近期开销。
- 异常：空组织提供创建档案/目标入口；数据失败不显示虚假零值。
- 权限与安全：全部统计由当前组织 API 返回；系统管理员跨组织需显式切换。

## 目标与模型档案（targets）

- 路径/流程：供应商 → 模型档案 → 目标 → 预检。
- 信息/操作：名称、Endpoint、协议、模型、组织/环境/渠道/标签；只写 Key 和自定义 Header；能力/公开限制/单价。
- 异常：预检分鉴权失败、模型不存在、协议不兼容、网络错误和 SSRF；不计真实性分。删除目标须说明密文删除与历史保留。
- 权限与安全：目标写入与密钥替换分权限；响应只含掩码；编辑空 Key 不清除原 Key。

## 检测配置（run-new）

- 路径/流程：目标 → 检测包/基线 → 预算预估 → 创建运行。
- 信息/操作：quick/standard/deep/custom；重复次数、stream、档位、并发、重试、时间/请求/Token/费用预算。
- 异常：费用未知显示未知而非 0；超预算请求需要降低配置；自定义/高成本包单独授权。
- 权限与安全：提交前显示调用成本和数据范围；冻结版本、估算和参数。

## 任务进度（run）

- 路径/流程：QUEUED → RUNNING → ANALYZING → 结果。
- 信息/操作：阶段、探针进度、成功/失败、Attempt 链、Token/费用、取消、选中探针复测。
- 异常：断线显示重连；Last-Event-ID 恢复后重新 GET 状态；取消保留已发生费用和样本；PARTIAL/FAILED 明确原因。
- 权限与安全：SSE 不传正文、Key 或 Endpoint query；仅管理员/审计员或创建人可停止（按权限矩阵）。

## 结果总览与历史（result）

- 路径/流程：四维风险 → 关键发现 → 探针 → 样本；历史 → 对比。
- 信息/操作：模型完整性风险指数；Prompt/Token/Response/Evidence；置信度；A/B/C/D；完整性；建议与替代解释。
- 异常：无有效样本显示信息不足、不是低风险；黑盒最高 B；规则不同的历史记录标记算法变化。
- 权限与安全：颜色与文字/数值并用；不自动改变生产渠道；自报告视觉隔离、权重恒为 0。

## 探针与样本证据（evidence）

- 路径/流程：Finding → Rule/version → sample → attempts。
- 信息/操作：阈值、实际值、效应量/区间、样本引用；Token 阶梯散点/中位数/y=x/平台/stream/质量；配对差异。
- 异常：正文过期/已关闭留存显示原因但仍展示摘要与哈希；无权限不显示正文；目标已删仍可看保留结果。
- 权限与安全：正文访问需权限与审计；请求模板只含 ${API_KEY} 占位符；上游内容纯文本转义。

## 可信基线（baselines）

- 路径/流程：创建草稿 → 有权审批 → 生效 → 到期/退役。
- 信息/操作：来源 official/historical、run、模型/协议/参数/区域、规则、有效期、审批记录。
- 异常：过期基线不可伪装为当前可信对照；普通用户无法审批/覆盖；同批配对变量必须一致。
- 权限与安全：基线和凭证仅属于组织；来源 official 只是来源声明，不自动获得信任。

## 规则与模板（rules）

- 路径/流程：草稿 → 回放 → 达标 → 发布 → 冻结/退役。
- 信息/操作：版本、内容 SHA-256、模板/tokenizer、阈值/权重、数据集拆分和回放指标。
- 异常：哈希变化或指标未达标禁止发布；退役不改变历史 Run 快照；安全审核状态单列。
- 权限与安全：仅规则管理员发布；不能用开发集结果代替独立验收；不向前端打包私有模板。

## 人工复核与报告（review）

- 路径/流程：算法快照 → 复核说明 → JSON/HTML 报告 → 下载。
- 信息/操作：确认/误报/待观察/不适用、历史、导出范围、schema/version/hash、免责声明。
- 异常：报告生成失败可重试，不丢结果；过期样本不改原报告；人工意见不覆盖原算法分。
- 权限与安全：导出前提示范围并审计；不含凭证/密文；只读导出需授权。

## 审计日志（audit）

- 路径/流程：筛选组织/时间/操作者/动作 → 完整性状态。
- 信息/操作：初始化、登录失败、权限/密钥/规则/基线变更、导出、正文读取、删除摘要。
- 异常：链验证失败显示系统异常；缺失数据不称验证通过；无普通删除/修改入口。
- 权限与安全：仅脱敏动作摘要；链密钥及 HMAC 不显示；维护清理独立权限。

## 账号、组织与系统（system）

- 路径/流程：成员/角色 → 配额/保留策略 → 健康 → 备份/恢复。
- 信息/操作：用户、组织、成员角色、供应商模型；版本/数据库/schema/Job/key/审计/报告存储；备份任务。
- 异常：加载、空数据、403、409 冲突、503 不就绪、迁移/恢复失败；保留策略 0～180 天正文，密钥独立保管。
- 权限与安全：普通组织管理员不是系统跨租户管理员；敏感变更需要权限/理由与审计。

## 共用交互

所有列表使用服务端分页及组织作用域，提供加载、空状态、失败重试、权限不足、数据过期/对象已删除状态；失败状态不能清空已有数据并冒充空列表。导航守卫只作体验，后端必须独立执行 RBAC/租户隔离。

表单标签、字段错误关联、键盘焦点、禁用重复提交、提交成功确认需实现。冲突刷新后重新提交，不静默覆盖并发修改。密钥输入不缓存，不把错误响应里的敏感详情直接展示。移动端表格允许横向滚动，风险信息不只依赖颜色。

尚未实现的后端能力不得在实际产品中返回示例数据。原型中的占位框明确用于布局审核；运行时 UI 必须逐页接真实 API，完成标准以开发台账与 E2E 证据为准。
