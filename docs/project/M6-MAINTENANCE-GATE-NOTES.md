## 已落实现（root 已复核，正式审核待统一进行）

- migration21：system_maintenance singleton、system_maintenance_operations、不可变 system_maintenance_events；模式闭集 normal / backup_freeze / restore_isolated。
- 普通 admission 与 ReadMaintenanceState 现在同样校验认证来源。Abort 后 normal 保留终态操作指针；只有 version1/gen0/time0 且没有任何操作历史才可视为初始 normal。当前 generation 必须等于有索引的最新历史 generation；操作必须指向其真正最新不可变事件，且事件 AfterMode/AfterVersion/AfterGeneration/ObservedAt 与 singleton 精确相同。只读状态用原一致性快照读取器，防跨提交拼接。migration21 追加 generation 唯一索引与 audit source 复合索引，使新增查询有界。
- 新 system_maintenance*.go：私有 maintenance purpose；普通参与写第一锁为 singleton SHARE，模式变化第一锁 UPDATE，然后保持旧 management / Job / org / execution 锁序。SQLite 使用原 BEGIN IMMEDIATE。没有网络工作在锁内。
- BeginBackupMaintenance / TakeOverExpiredBackup 创建私有 owner+generation 能力；60 秒 lease / 请求硬上限不超过 24 小时，短操作 context 2 秒，时间由锁后数据库时钟决定。Renew/Abort 校验真实 system admin、当前会话、原 lease 和 generation，并在审计后再次检查原会话自然到期及原租约。过期不自动解锁；没有恢复激活 API。
- 操作的 scope 明确为 system。使用既有持久 initial_organization_id 作系统审计锚点，而不是操作者所属组织或新造 system org；非成员 sysadmin 也追加该全库动作。不可变事件闭集摘要通过 ObjectID `<operationID>:<SHA256>` 绑定到固定 action 的现有 HMAC 审计链；最大 84 字节，在原 128 上限内。事件没有 owner token、路径、DSN、密钥或自由正文。迁移禁止事件 UPDATE/DELETE 和删除操作历史。
- 新业务 Run、预检、报告、通用 enqueue 及管理变更在冻结时拒绝。私有 TenantTransaction 入场标记使已入场的 WithLease/CompleteWith/可信 reconcile 能继续提交内部后续 Job，外部调用者不能从公开 bool/context 赋予该标记。
- Claim 在冻结/恢复隔离暂停；原 in-flight Renew、CheckLease、结算/失败的 fence 和期限不变。备份冻结保留取消、历史报告下载审计。定期 draft 删除、retention 排程和 runtime bundle 同步暂停；恢复隔离还暂停普通 reconcile。登录会话/审计和历史读取保留，ChangePassword 被隔离挡住。
- Observe 只返回观察时刻以及 running Job、expired running Job、DISPATCHED Attempt 三个布尔事实。没有 snapshot permit 或 SnapshotEligible 字段；没有 lease 或阻塞项不证明外部请求停止。本单元不把失联/expired Job 改成完成，不发起新付费调用。
