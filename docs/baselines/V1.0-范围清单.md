## 2. V1.0 必须交付能力

- 独立初始化、本地登录、用户、组织、RBAC、供应商、模型档案和审计。
- OpenAI-compatible Chat Completions 非流式 JSON 与 SSE 流式协议。
- 目标、只写 Secret、预检、数据库 Job、Worker、预算、取消、恢复和探针复测。
- 五类 P0 提示词行为探针；Token 阶梯、Usage、终止、结构完整性和流/非流检测。
- 四维风险、综合风险、置信度、A/B/C/D 证据、Finding、可信基线和人工复核。
- JSON/HTML 报告、历史趋势、结果下钻、规则回放和版本冻结。
- 单机包、Docker Compose、迁移、升级检查、备份恢复、健康检查、监控和告警。
- Mock upstream、开发/校准/回归/盲验收数据集、功能/算法/安全/性能/恢复验收。

## 3. 明确不进入 V1.0

- 周期复检和 Webhook 通知；
- 多目标同批对照操作界面（数据模型保留扩展能力）；
- Responses API、Anthropic/Gemini 原生协议和多模态；
- 工具调用契约探针；
- PDF/CSV 报告和完整报告版本链；
- Kubernetes/Helm；
- 密码学制品签名和规则/模板/tokenizer 包签名（V1.0 必须提供 SHA-256 完整性校验、版本追踪和 SBOM）；
- Redis/NATS/云队列、S3、OIDC、KMS 的强制依赖；
- 自动停用目标、自动改变外部渠道或生产流量；
- 跨组织共享密钥或共享官方基线账号。

## 4. 不可降低的发布线

- 固定输出上限检出率 ≥95%；
- 分段/概率输出上限检出率 ≥90%；
- 稳定隐藏指令行为检出率 ≥85%；
- 正常接口及困难阴性误报率 ≤5%；
- API Key 明文泄漏、跨组织越权、SSRF 禁止地址绕过均为 0；
- P0 缺陷、严重及高危安全缺陷均为 0；
- 黑盒证据最高 B，模型自述权重恒为 0；
- 无 Redis/S3/OIDC/KMS 时核心功能 100% 可用。

## 5. 变更边界

新增协议/模型类型、改变风险表述、修改保留策略、评分/置信度/证据公式、降低验收线、引入强制外部依赖或产生自动外部副作用，均必须执行计划第 9 节变更评审。未经批准，不得在实现中隐式变更。
